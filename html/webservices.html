spotei webservices

The spotei webservices developed in Transcription+ are hosted by the Academy of Sciences and Humanities in Hamburg.
You can consult the Swagger documentation at: https://transcription-plus.awhamburg.de/spotei-web/docs/index.html .
A web interface for experimenting with the services is at: https://transcription-plus.awhamburg.de/spotei-web/index.html .

You can find the corresponding sources in this GitHub repository.

TEILicht webservices

The TEILicht webservices were developed by Bernhard Fisseni for the CLARIN-D project (see references).
A landing page for the current version of, hosted at IDS Mannheim, is at https://clarin.ids-mannheim.de/teilicht/.
You can find the corresponding sources in this GitHub repository.

The TEILicht webservices are integrated in the WebLicht tool chainer.
